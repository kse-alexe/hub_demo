# PMO Analytics Hub — демо

Одностраничный аналитический хаб для PMO: реестр проектов, квалификация проектов после ППМ и аналитика поверх них. Без сервера и без сборки — открывается как обычный `index.html`.

> **Все данные в демо вымышлены.** Клиенты заменены отраслями, суммы иллюстративные (от 100 тыс. до 10 млн ₽), люди обозначены только именами. Изменения, которые вы вносите в интерфейсе, сохраняются только в вашем браузере, кнопка «Сбросить к исходным данным» возвращает исходный набор из 50 проектов.

## Что внутри

- **Реестр проектов 2026** — карточки со статусом, кварталом, суммой, маржой план/факт, ответственными; поиск и фильтры по кварталу, клиенту, продукту, проджекту, квалификации и статусу; конструктор полей карточки.
- **Квалификация проекта (29 баллов)** — четыре блока: бизнес-результат, клиент, команда, управление проектом. Категория («Удачный» от 24, «Рабочий» от 18, «Рискованный» от 11, иначе «Нежелательный») подсказывается автоматически по сумме баллов; для проектов без оценки есть отдельное состояние «Пока не оценено».
- **Архив 2025** — закрытые проекты с упрощённой оценкой по удовлетворённости.
- **Аналитика** — маржа план vs факт по кварталам, распределение квалификаций, продукты, форматы, места проведения и размеры групп, сравнение годов, выручка по клиентам, загрузка кураторов, проджектов и фасилитаторов.
- **Годы без правки кода** — кнопка «Добавить год» архивирует предыдущий год и открывает новый.

## Как это сделано с ИИ

Хаб строился итеративно в диалоге с Claude: от структуры двух таблиц и логики квалификации до интерфейса, аналитики и проверок целостности данных. Эта демо-версия получена из рабочей автоматически:

1. Скрипт-генератор создал вымышленный набор данных со схемой, идентичной рабочей: отрасли вместо клиентов, суммы в заданном диапазоне, баллы квалификации с правдоподобным разбросом и категориями, посчитанными по тем же порогам. Показатели маржи в баллах квалификации привязаны к плану и факту маржи проекта.
2. Скрипт-сборщик заменил бренд, шрифт, цвета и серверную часть на нейтральные, причём каждая замена проверяется на точное число совпадений, а сборка падает, если в файле остались следы рабочей версии.
3. Автоматическая проверка в headless-браузере сверила карточки, таблицы и графики с независимым пересчётом по данным: 48 проверок по количеству проектов, суммам, марже, квалификациям, продуктам, форматам и клиентам (для всех лет, для 2025 и для 2026).
4. Дизайн проверен по принципам Web Interface Guidelines и доработан: управление с клавиатуры (карточки и строки открываются Enter/Space, Esc закрывает окна, фокус не выходит за пределы диалога и возвращается на кнопку), подписи ко всем полям, текстовое описание каждого графика, собственные диалоги подтверждения вместо встроенных, контраст бейджей от 4.5:1 в светлой и тёмной темах. Ещё 36 автоматических проверок в браузере подтверждают это.

В рабочей версии данные хранились на общем сервере с паролем команды и выгружались еженедельно; в демо серверной части нет.

## Запуск

Откройте `index.html` в браузере. Графики подключаются через Chart.js с CDN, поэтому нужен интернет.

Для публикации на GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
